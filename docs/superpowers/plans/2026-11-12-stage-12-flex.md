# Stage 12: `IBKRFlex` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A second library product, `IBKRFlex`, that downloads a Flex report from IB's Flex Web Service by token and
query id (the two HTTPS steps of `ib_async`'s `FlexReport`) and reads its XML as records by topic (`topics`,
`extract`).

**Architecture:** A Foundation-only target with no link to `IBKR`.
- Task 1 parses: one small `XMLParser` delegate records every element in document order (tag, attributes, depth,
  direct text); `FlexReport` keeps the bytes and that list; `topics` and `extract` filter it into `FlexRecord`s of
  IB's attribute strings, with a strict `Decimal` accessor.
- Task 2 downloads: `download` asks SendRequest through an injectable `FlexTransport` closure, then polls
  GetStatement, parsing every answer with Task 1's `FlexReport(data:)` and deciding from its root and first children
  whether it is still generating, IB's error or the report.

**Tech Stack:** Swift 6 (tools 6.0), SwiftPM, Foundation (`XMLParser`, `URLSession`), Swift Testing.

**Spec:** `docs/superpowers/specs/2026-11-12-parity-and-1.0-design.md`: item 5 (line 49, a separate product
`IBKRFlex` so that `IBKR` does not pull in URLSession), line 87 (XML parsing is the point of `IBKRFlex`, the one
exception to «IB's XML stays `String`»), and stage 12 (line 158: two HTTPS steps as `ib_async`, `topics` /
`extract`, tests on hand-written XML and a fake HTTP layer, the live check a KNOWN-GAPS line). Behaviour reference:
`ib_async` `flexreport.py` (read, never run, never copy). The controller's rulings for this stage are folded into the
constraints and tasks below and are not open.

## Review Focus

1. **Cancelling a download that is still polling.** The loop is unbounded by design; a cancelled caller must get
   `CancellationError` at the next sleep and no further GetStatement may go out. Test: Task 2
   `cancellingStopsThePolling`.
2. **A token with reserved characters.** The token goes into a query string; `&` or a space in it must not split or
   corrupt the query. Test: Task 2 `theTokenIsEscaped`.
3. **Escaped attribute text.** Real descriptions hold `AT&amp;T`; the record must read `AT&T`, not the entity or a
   cut string. Test: Task 1 `extractReturnsEveryElementInDocumentOrder`.
4. **An empty or cut-off body.** An empty GetStatement answer or a truncated report must throw `.malformedXML`, never
   come back as a report with no topics. Tests: Task 1 `malformedXMLThrows`, Task 2 `malformedAnswersThrowMalformedXML`.
5. **Number text that only looks like a number.** `" 5"`, `"1,000"`, `"12abc"`, `"1."` must read as `nil`, while plain,
   negative and exponent forms read exactly. Test: Task 1 `decimalReadsOnlyWholeNumbers`.

```swift
func parseFlexXML(_ data: Data) throws -> [FlexElement] {
    let collector = FlexElementCollector()
    let parser = XMLParser(data: data)
    parser.delegate = collector
    // An empty document can parse "successfully" on some platforms; a report needs a root.
    guard parser.parse(), !collector.elements.isEmpty else {
        throw FlexError.malformedXML(parser.parserError?.localizedDescription ?? "no XML element")
    }
    return collector.elements
}

private final class FlexElementCollector: NSObject, XMLParserDelegate {
    var elements: [FlexElement] = []
    private var open: [Int] = []   // indices of the elements still open, innermost last

    func parser(_ parser: XMLParser, didStartElement elementName: String, namespaceURI: String?,
                qualifiedName qName: String?, attributes attributeDict: [String: String] = [:]) {
        open.append(elements.count)
        elements.append(FlexElement(name: elementName, attributes: attributeDict, depth: open.count - 1, text: ""))
    }

    func parser(_ parser: XMLParser, didEndElement elementName: String, namespaceURI: String?,
                qualifiedName qName: String?) {
        open.removeLast()
    }

    func parser(_ parser: XMLParser, foundCharacters string: String) {
        if let index = open.last { elements[index].text += string }
    }
}
```
